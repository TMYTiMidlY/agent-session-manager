# ADR 0004：DSH 只读转录与 runtime 恢复解耦

## 状态

已接受。规范化与保真度遵循 [ADR 0003](0003-archive-reconstruction-fidelity.md)。

## 背景

旧适配器把锁定的 DSH 官方 codec/runtime 固化进 bundle，并通过严格迁移与 Session 恢复来提取转录。恢复可运行状态需要校验完整事件词汇、描述符版本、模型 surface 与引用；这些要求并不等于“读出人类对话”。无关的 subagent descriptor 子格式升级就会让整份归档拒读，继续升级 pin 只能暂时追上上游。

## 决策

- 将压缩/JSONL 字节读取、事件信封与历史消息布局适配、转录投影分层。DSH 适配器不再依赖官方 Session/codec 包，不启动 runtime、插件或上游迁移链。
- 固化已经核对的旧版**转录载体布局**，而不是复刻完整恢复语义：平铺/共享消息、工具包装/一等工具消息、steering/compact/code-dispatch 别名，以及旧版 packed 流片段的序号宽度。既有归档向后兼容。
- 只校验实际使用的身份、状态、正文与关联字段。具名非 user 来源、系统/开发者上下文、描述符、团队状态和其他已知 log-only 事件按明确投影规则有意忽略；不维护其私有 payload schema。额外字段不阻断读取。
- 人类转录读取原始追加消息，不折叠当前模型 surface；不将 replacement、流片段或失败尝试伪装成新对话。继承历史已在日志中，不加载父会话，也不在续种标记处截断。
- 工具关联仅在一一关系可验证时成立。保留原始 seq 与历史范围引用；明确但无效的 provenance 不回退猜测。重复标识/seq 或不一致的 PTC 生命周期保留独立结果，不生成推断决策。
- 新 header 版本按已知物理布局尽力读取并显式告警，不将版本号当作拒读开关。未知事件/内容/surface 与畸形记录采用局部省略和有界、无 payload 的诊断，继续读取其余消息。
- 兼容性不足和内容损失通过诊断及共享来源警告暴露；搜索无命中也报告读取警告。无效 header、解压/I/O 失败和编码选择歧义仍是明确错误，绝不静默回退到旧一代。

## 后果

- DSH 的无关元数据/描述符升级不再要求重新 pin、打包、发布 asmgr；单文件分发可以保留。
- 这是转录读取器，不是 DSH 状态迁移器、恢复器或上游校验器；“可读”不表示“可以 resume”，`source.lossy: false` 也不承诺保存全部 runtime 状态。
- 真正改变压缩、信封或可见消息语义的未来格式仍可能需要新增能力；不得声称任意未知未来版本完全兼容。
- 回归覆盖旧版布局、当前 descriptor、模拟未来 header/未知事件、局部损坏、隐私排除、工具问答与各输出的警告。私有真实语料只能做本地只读核验，不提交或上传其正文。
